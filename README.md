# 研究生助手 · Android

把课程、校历和个人日程放在一起查看的手机应用。课表读取或导入后保存在手机上，断网也能查看；也可以手动添加自己的课程和事项。

**[下载最新安装包](https://github.com/Haroxa/graduate-assistant-releases/releases/latest)** · [查看历史版本](https://github.com/Haroxa/graduate-assistant-releases/releases) · [反馈问题](https://github.com/Haroxa/graduate-assistant-releases/issues)

## 适用范围

- 支持 Android 8.0 及以上系统。
- 当前学校课表读取适配**武汉理工大学研究生系统**，内置校历和教学周覆盖 **2026–2027 学年第一学期**。
- 其他学校的自动读取和其他学期尚未适配。手动排课也使用当前内置学期，请先确认日期范围适合自己。
- 安装包不预装任何人的课表、账号或个人事项。学校登录与课表读取仍需在不同真实手机上进一步验证。

## 应用功能

| 功能 | 可以做什么 |
| --- | --- |
| 周课表 | 切换教学周，查看课程时间和地点；默认紧凑七天布局，也可切换宽列、横向查看和缩放。 |
| 全学期与非本周课程 | 全学期查看课程分布；开启“非本周”后用浅色提示其他周的课程，重叠时各自分列，点击可查看详情和定位授课周。 |
| 课程列表 | 搜索课程、教师和地点；区分导入与自建课程，按星期、教学周、时段及已有课程属性筛选。 |
| 手动添加课程 | 从课程列表添加，或在周课表空白格选中后再次点击添加；选择日期、星期、教学周和节次，支持多个上课时段。 |
| 日历 | 按月或按学期连续查看校历、课程和个人事项；点日期查看当天安排。 |
| 我的日程 | 添加、查看、编辑手机创建的个人事项，按近期、全部和历史筛选；支持全天、起止时间、地点、备注和提前提醒。 |
| 桌面小组件 | 提供“近期安排”和“本周安排”，查看最近两项或按周选择日期查看课程与个人事项，点击进入对应日期。 |
| 离线与更新 | 已保存的安排可离线查看；首页可检查应用更新，下载校验后由系统确认安装。 |

底部入口为 **首页／安排／设置**。“安排”内切换 **课表／日历／我的日程**，课程列表入口在课表工具栏中。

## 下载与安装

1. 打开[最新版本页面](https://github.com/Haroxa/graduate-assistant-releases/releases/latest)，在 **Assets** 中下载 `graduate-assistant.apk`，无需下载源码压缩包或 `update.json`。
2. 在手机上打开 APK，按系统提示允许此次安装。首次安装可能需要为浏览器或文件管理器开启“安装未知应用”权限。
3. 已安装旧版时，直接覆盖安装；也可在应用首页点“检查更新”。应用会核对安装包版本、大小和 SHA-256，再交给系统安装器确认。

覆盖安装通常保留本机数据。若提示签名不一致，不要直接卸载：卸载会丢失应用私有数据，请先确认使用的是本仓库发布的安装包。每个 Release 附带的 `update.json` 是更新校验信息，不是课表文件。

## 第一次使用

### 获取或添加课程

**从学校读取：** 首页点“从学校更新课表”，在学校官方网页登录，进入研究生系统首页后读取本人课表。核对账号和课表预览，再确认保存；读取失败时不会要求你先删除已有课表。

**已有离线文件：** 在“设置”中点“导入课表文件”，选择本应用支持的课表 HTML 文件。普通网页、Excel、截图和 `update.json` 不能直接作为课表导入。尚未提供通用格式转换工具。

**手动添加：** 在“安排 → 课表 → 课程列表”点“添加课程”；也可选择具体教学周，点空白节次，选中后再次点“＋”添加。空白格入口预填所点星期、单节和当前周，需要多周或多节时在编辑页调整，保存前核对安排。

导入课程只读，学校更新会刷新导入部分；自建课程可编辑、删除，与导入部分分开保存。自建课程按学校账号和学期隔离，切换账号不会混用；登录前创建的课程也不会自动转到新账号。重叠或同名课程保存前会提示核对。

### 查看课表

- **紧凑**适合快速看一周，**宽列**适合阅读长名称和重叠课程；点课程可查看完整信息。
- “非本周”默认隐藏，开启后显示明确的浅色标记；这些提示不代表当前周上课，也不计入当天安排、提醒或组件统计。本周实际课程和事项优先显示。
- “全学期”汇总不同教学周的课程，不代表所有课程在同一周同时发生。
- 校历休息日作为参考；手动课程按所选教学周排课，不会自动跳过节假日。

### 添加事项和提醒

在“安排 → 日历”选择日期并点“添加事项”，或在“我的日程”中添加。起止时间使用滑动选择；保存后点整张事项卡片查看详情，手机创建的事项可在详情中编辑或删除。

开启提前提醒后，Android 13 及以上需要允许通知。全天事项以当天 **09:00** 为提醒基准，系统省电策略可能使通知延迟；本应用目前不提供课程提醒，也不写入手机系统日历。

“历史”仅表示日期早于今天，不代表事项已完成。导入的个人事项可以查看，暂不支持在手机编辑，也不发送本机提醒。

### 添加桌面小组件

在手机桌面长按空白处，打开系统“小组件”，选择研究生助手的“近期安排”或“本周安排”。两种组件均支持调整尺寸，实际网格由手机桌面决定。

- **近期安排**（原“今日课程”）：默认 4×2，显示最近两条课程或个人事项，保留起止时间、地点、日期和类别。在应用“设置 → 桌面组件展示范围”中选择未来 7、14、30 天或全学期。
- **本周安排**：默认 4×4，七日导航显示每天的安排数量；点日期切换列表，顶部按钮切换周或回到今天。较小高度显示两条，足够高时显示四条，超出部分可点击“查看当天全部”。各组件独立记住日期选择，点今天后自动跟随日期。此组件不受近期展示范围设置影响。

0.51.0 起不再提供“下一节课”的新添加入口，已有组件沿用“近期安排”的展示。桌面和省电策略可能影响定时刷新。

## 数据与使用限制

- 学校登录 Cookie 留在手机 WebView；当前学校读取流程不上传到个人云端。课表、自建课程和手机创建的事项存储在应用私有目录。
- 更新学校课表和导入文件不会覆盖手机创建的事项或自建课程。清空导入课程前会保存回退副本，可在本机课表管理中恢复。
- 不同设备之间暂不自动同步，也没有通用的自建课程和事项导出功能。清除应用数据或卸载会丢失本机记录。
- 学校接口、网络或登录状态变化可能导致读取失败；已保存的安排仍可离线查看。部分课程属性可能显示“待补充”。
- 学校正式通知和课表变更请以学校系统为准；本应用不替代学校选课、考勤或通知系统。
