# Graduate Assistant Android Releases

This public repository hosts signed Android APK releases for the Graduate Assistant app. Source code, signing keys, school data and personal schedules are stored separately and are not published here.

Download the latest APK from [Releases](https://github.com/Haroxa/graduate-assistant-releases/releases). Android asks for confirmation before installation. Each release also includes update.json with the APK version, size and SHA-256 checksum.
